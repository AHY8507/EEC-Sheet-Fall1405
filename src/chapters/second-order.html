• معادله دیفرانسیل RLC موازی و سری را استخراج کنیم و ضریب میرایی \(\alpha\) و فرکانس طبیعی \(\omega_0\) را بفهمیم.
  • چهار نوع پاسخ (فوق‌میرا، بحرانی، زیرمیرا، بی‌اتلاف) را از روی ریشه‌ها تشخیص دهیم و شهود فیزیکی هر کدام را بدانیم.
  • ثابت‌ها را از \(x(0^+)\) و \(x'(0^+)\) پیدا کنیم و پاسخ کامل با ورودی پله را بنویسیم.
  • فراجهش را حساب کنیم، مدار را برای میرایی بحرانی طراحی کنیم و اثر منبع وابسته روی میرایی را ببینیم.
  • پاسخ ضربه RLC موازی را مستقیم از تأثیر ضربه بر شرایط اولیه بسازیم.

    وقتی یک خازن و یک سلف در مدار باشند (و حلقه خازنی یا کات‌ست سلفی آن‌ها را به هم وابسته نکند)، انرژی می‌تواند بین آن‌ها رفت‌وبرگشت کند: میدان الکتریکی ↔ میدان مغناطیسی. نتیجه، پدیده‌ای است که در مرتبه اول نبود: نوسان. مقاومت این نوسان را میرا می‌کند. کل داستان مرتبه دوم رقابت این دو است.

    RLC موازی بدون ورودی

  • KCL در گره بالا (همه جریان‌ها خروجی): \(\dfrac{v}{R} + i_L + C\dfrac{dv}{dt} = 0\).
  • \(i_L\) را حذف کنیم: یک بار مشتق بگیرید و از \(\dfrac{di_L}{dt} = \dfrac{v}{L}\) استفاده کنید: \(\dfrac{1}{R}\dfrac{dv}{dt} + \dfrac{v}{L} + C\dfrac{d^2v}{dt^2} = 0\).
  • تقسیم بر \(C\): \(v'' + \dfrac{1}{RC}v' + \dfrac{1}{LC}v = 0\).
  • حدس \(e^{st}\): \(s^2 + \dfrac{1}{RC}s + \dfrac{1}{LC} = 0\).

    RLC سری

    KVL (بدون منبع): \(Ri + L\dfrac{di}{dt} + v_C = 0\) با \(i = C\dfrac{dv_C}{dt}\). یک بار مشتق: \(Ri' + Li'' + \dfrac{i}{C} = 0\)، پس \(s^2 + \dfrac{R}{L}s + \dfrac{1}{LC} = 0\). (همان معادله با \(v_C\) هم به دست می‌آید.) دوگان RLC موازی است (فصل B7).

    هر دو معادله را به شکل استاندارد می‌نویسیم:

    \[ s^2 + 2\alpha s + \omega_0^2 = 0 \qquad\Longrightarrow\qquad s_{1,2} = -\alpha \pm \sqrt{\alpha^2 - \omega_0^2} \]

    \(\omega_0\) سرعت رفت‌وبرگشت انرژی بین L و C است (فنر و وزنه، فصل A8). \(\alpha\) سرعت تلف شدن انرژی در R است. در سری، R بزرگ جریان را کم می‌کند و زود همه‌چیز را خاموش می‌کند؛ در موازی، R کوچک مسیر نشتی آسانی است که انرژی را سریع تلف می‌کند.

    پاسخ ضربه RLC موازی

    ضربه جریان \(\delta(t)\) که به گره RLC موازی تزریق شود، در لحظه صفر باید جایی برود. سلف (جریانش نمی‌پرد) و مقاومت (ولتاژ هنوز صفر است) مسیر آن نیستند؛ پس همه‌اش وارد خازن می‌شود و بار ۱ کولن روی آن می‌نشیند: \(v(0^+) = \frac{1}{C}\). بعد از آن ورودی صفر است. پس پاسخ ضربه = پاسخ ورودی صفر با شرط اولیه‌ای که ضربه ساخته.
  • \(\alpha = \frac{1}{2RC} = 0.5\)، \(\omega_0 = 1\) ⇒ زیرمیرا، \(\omega_d = \sqrt{0.75} = 0.866\).
  • \(v(0^+) = 1/C = 1\,\text{V}\)، \(i_L(0^+) = 0\).
  • \(v'(0^+) = \dfrac{i_C(0^+)}{C} = -\dfrac{v/R + i_L}{C} = -1\,\text{V/s}\).
  • \(v = e^{-0.5t}(A\cos0.866t + B\sin0.866t)\): \(A = 1\)؛ \(-0.5 + 0.866B = -1 \Rightarrow B = -0.577\).
    •

    \(h(t) = e^{-0.5t}\big(\cos0.866t - 0.577\sin0.866t\big)\,u(t)\)

    RLC موازی با \(L = 1\,\text{mH}\)، \(C = 10\,\text{nF}\). برای \(R = 100\Omega\)، \(158\Omega\) و \(1\text{k}\Omega\) نوع پاسخ و \(Q\)؟

    \(\omega_0 = 1/\sqrt{10^{-11}} = 316\text{k rad/s}\). \(Q = R\sqrt{C/L} = R\times3.16\times10^{-3}\): برای ۱۰۰Ω، \(Q = 0.316\) (فوق‌میرا)؛ ۱۵۸Ω، \(Q = 0.5\) (بحرانی)؛ ۱k، \(Q = 3.16\) (زیرمیرا، حدود ۳ نوسان قابل مشاهده قبل از خاموشی).

    جمع‌بندی فصل

    • \(s^2 + 2\alpha s + \omega_0^2 = 0\)؛ سری \(\alpha = R/2L\)، موازی \(\alpha = 1/2RC\)، هر دو \(\omega_0 = 1/\sqrt{LC}\).
    • \(\alpha > \omega_0\) فوق‌میرا، \(=\) بحرانی، \(<\) زیرمیرا (نوسان با \(\omega_d\))، \(\alpha = 0\) بی‌اتلاف.
    • دو ثابت از \(x(0^+)\) و \(x'(0^+)\)؛ با جواب کامل تطبیق دهید.
    • فراجهش پله زیرمیرا: \(e^{-\pi\alpha/\omega_d}\). بحرانی: \(R = 2\sqrt{L/C}\) (سری).
    • منبع وابسته می‌تواند میرایی را کم، صفر (نوسان‌ساز) یا منفی (ناپایدار) کند.
    • پاسخ ضربه = پاسخ ورودی صفر با شرایط اولیه‌ای که ضربه ساخته.

    تمرین‌ها

    RLC سری با \(R = 10\Omega\)، \(L = 0.1\,\text{H}\)، \(C = 1\,\text{mF}\). \(\alpha\)، \(\omega_0\) و نوع پاسخ؟

    \(\alpha = 50\)، \(\omega_0 = 100\)؛ زیرمیرا، \(\omega_d = 86.6\,\text{rad/s}\).

    RLC سری با \(R = 4\Omega\)، \(L = 2\,\text{H}\)، \(C = 0.5\,\text{F}\)، \(v_C(0) = 2\,\text{V}\)، \(i(0) = 1\,\text{A}\)؛ منبع پله ۱۰V در صفر وصل می‌شود. \(v_C(t)\)؟

    \(s^2 + 2s + 1\) ⇒ بحرانی \(s = -1\). \(v_C = 10 + (A + Bt)e^{-t}\)؛ \(A = -8\)؛ \(v_C'(0) = 1/0.5 = 2 = B - A \Rightarrow B = -6\). \(v_C = 10 - (8 + 6t)e^{-t}\).

    در RLC موازی با \(L = 1\,\text{H}\) و \(C = 1\,\text{F}\)، \(R\) را چنان انتخاب کنید که پاکت نوسان با ثابت زمانی ۴ ثانیه میرا شود. \(\omega_d\)؟

    \(\alpha = 1/4 = 1/(2R)\) ⇒ \(R = 2\Omega\)؛ \(\omega_d = \sqrt{1 - 1/16} = 0.968\).

    ثابت کنید در RLC سری بدون ورودی، \(\frac{d}{dt}\left(\frac12Li^2 + \frac12Cv_C^2\right) = -Ri^2\). معنی‌اش چیست؟

    مشتق: \(Lii' + Cv_Cv_C' = i(Li' + v_C) = i(-Ri) = -Ri^2\) (با \(Cv_C' = i\) و KVL). انرژی کل فقط به اندازه توان تلف‌شده در R کم می‌شود؛ با \(R = 0\) انرژی ثابت است.
