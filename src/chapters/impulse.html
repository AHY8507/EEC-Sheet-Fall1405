• بفهمیم پاسخ ضربه چرا مهم است: پاسخ به هر ورودی از روی آن ساخته می‌شود.
  • شکل \(h(t)\) را از روی معادله دیفرانسیل حدس بزنیم: جواب همگن × \(u(t)\)، به‌علاوه ضربه‌ها وقتی درجه ورودی به اندازه کافی بالاست.
  • ضرایب را با «تطبیق ضرایب ضربه» پیدا کنیم و دلیلش (هم‌جنس بودن دو طرف) را بفهمیم.
  • روش «شرایط اولیه معادل» را برای حالت ساده اثبات کنیم.
  • رابطه پاسخ پله و ضربه را به کار ببریم و جواب‌ها را با تابع تبدیل بررسی کنیم.
    •  second-order math-integral waveforms

    در فصل‌های قبل پاسخ ضربه را برای مدارهای خاص پیدا کردیم. اما گاهی فقط رابطه ورودی-خروجی به شکل یک معادله دیفرانسیل داده شده (مثلاً در یک سیستم کنترل، یا وقتی معادله مدار را نوشته‌ایم). این فصل یک روش کلی و مکانیکی برای یافتن \(h(t)\) مستقیماً از معادله می‌دهد.

    صورت مسئله

    پاسخ حالت صفر (همه شرایط اولیه \(0^-\) صفر) به ورودی \(w(t) = \delta(t)\). معادله کلی با ورودی \(w\) و خروجی \(y\):

    \[ y^{(n)} + a_{n-1}y^{(n-1)} + \dots + a_0y = b_mw^{(m)} + \dots + b_1w' + b_0w \]

    \(y^{(k)}\) یعنی مشتق \(k\)-ام. \(n\) مرتبه سیستم است.
    • برای \(t > 0\) ورودی صفر است، پس \(h(t)\) در آنجا جواب همگن است. با \(u(t)\) ضرب می‌کنیم چون قبل از صفر چیزی نبوده.
    • اگر \(m < n\): فقط همین: \(h(t) = [\text{جواب همگن}]\,u(t)\).
    • اگر \(m \ge n\): به‌علاوه جمله‌های ضربه: \(K_0\delta(t) + K_1\delta'(t) + \dots + K_{m-n}\delta^{(m-n)}(t)\).
  • سمت راست، با \(w = \delta\)، تیزترین جمله‌اش \(\delta^{(m)}\) است.
  • سمت چپ، تیزترین جمله‌اش از \(y^{(n)}\) می‌آید. اگر \(y\) شامل \(\delta^{(k)}\) باشد، \(y^{(n)}\) شامل \(\delta^{(k+n)}\) می‌شود.
  • برای برابری دو طرف باید \(k + n = m\)، یعنی \(y\) تا \(\delta^{(m-n)}\) داشته باشد. اگر \(m < n\)، حتی بدون ضربه در \(y\)، مشتق‌گیری‌ها (از پرش‌های \(y\) و مشتق‌هایش در صفر) به‌اندازه کافی ضربه می‌سازند.
    •

    ابزار: مشتق تابع بریده‌شده

    \[ \frac{d}{dt}\big[f(t)u(t)\big] = f'(t)u(t) + f(0)\,\delta(t) \]

    (فصل A4.) مثلاً \(\frac{d}{dt}[(K_1e^{-t} + K_2e^{-3t})u] = (-K_1e^{-t} - 3K_2e^{-3t})u + (K_1 + K_2)\delta\).

  • ریشه‌های معادله مشخصه را پیدا کنید و جواب همگن را با ثابت‌های مجهول بنویسید.
  • \(h\) = همگن × \(u(t)\) (+ جمله‌های ضربه اگر \(m \ge n\)).
  • \(h\) را در معادله بگذارید (با قاعده بالا مشتق بگیرید). جمله‌های \(u(t)\) خودبه‌خود حذف می‌شوند (چون جواب همگن است).
  • ضریب \(\delta, \delta', \delta'', \ldots\) دو طرف را برابر بگذارید و دستگاه را حل کنید.
    •

    حالت ساده: \(m = 0\) و شرایط اولیه معادل

  • معادله را از \(0^-\) تا \(0^+\) انتگرال بگیرید. اگر \(y, y', \ldots, y^{(n-1)}\) فقط پرش (و نه ضربه) داشته باشند، انتگرال همه جمله‌ها جز اولی صفر است.
  • \(\int_{0^-}^{0^+}y^{(n)}dt = y^{(n-1)}(0^+) - y^{(n-1)}(0^-) = \int\delta = 1\).
  • پس فقط بالاترین مشتق پایین‌تر از \(n\) یک واحد می‌پرد: \(y^{(n-1)}(0^+) = 1\)، و بقیه \(y(0^+) = \dots = y^{(n-2)}(0^+) = 0\).
  • نتیجه: \(h(t)\) = پاسخ ورودی صفر با این شرایط اولیه.
    •

    شهود: در RLC (فصل B12)، ضربه جریان فقط ولتاژ خازن را پراند، نه چیزهای دیگر. اینجا هم ضربه فقط «پایین‌ترین جایی که می‌تواند» اثر می‌گذارد.

    بررسی سریع با تابع تبدیل

    در فصل B14 می‌بینیم که با شرایط اولیه صفر، مشتق در حوزه لاپلاس به ضرب در \(s\) تبدیل می‌شود. پس معادله مستقیماً «تابع تبدیل» می‌دهد:

    \[ H(s) = \frac{b_ms^m + \dots + b_0}{s^n + a_{n-1}s^{n-1} + \dots + a_0}, \qquad h(t) = \mathcal{L}^{-1}\{H(s)\} \]

    اگر \(m \ge n\)، اول تقسیم چندجمله‌ای کنید: خارج‌قسمت جمله‌های ضربه (\(1 \to \delta\)، \(s \to \delta'\)) و باقیمانده کسر سره است. چند بررسی از مثال‌های بالا:

    • \(\dfrac{s + 1}{(s + 2)(s + 3)} = \dfrac{-1}{s + 2} + \dfrac{2}{s + 3}\) ⇒ \((-e^{-2t} + 2e^{-3t})u\) ✓.
    • \(\dfrac{3s + 1}{2s + 4} = 1.5 - \dfrac{2.5}{s + 2}\) ⇒ \(1.5\delta - 2.5e^{-2t}u\) ✓.
    • \(\dfrac{s^2 + 2s + 3}{s + 1} = s + 1 + \dfrac{2}{s + 1}\) ⇒ \(\delta' + \delta + 2e^{-t}u\) ✓.

    پاسخ ضربه، پاسخ پله و یک مدار

    \(h(t) = \dfrac{ds}{dt}\) و \(s(t) = \displaystyle\int_{0^-}^{t}h(\tau)\,d\tau\). مقدار نهایی پاسخ پله برابر \(H(0) = b_0/a_0\) است (بهره DC).

    برای \(y'' + 5y' + 6y = w\)، پاسخ پله را بیابید.

    \(s(t) = \int_0^t(e^{-2\tau} - e^{-3\tau})d\tau = \left[\frac{1 - e^{-2t}}{2} - \frac{1 - e^{-3t}}{3}\right] = \left(\frac16 - \frac12e^{-2t} + \frac13e^{-3t}\right)u(t)\). مقدار نهایی \(\frac16 = H(0) = \frac{1}{6}\) ✓.

    RC سری با ورودی \(v_s\) و خروجی \(v_R\). معادله دیفرانسیل را بنویسید و \(h(t)\) را با تطبیق ضرایب بیابید.

  • \(v_R = Ri = RC\dfrac{dv_C}{dt}\) و \(v_C = v_s - v_R\). پس \(v_R = RC(v_s' - v_R')\)، یعنی \(RC\,v_R' + v_R = RC\,v_s'\).
  • \(m = n = 1\): \(h = K_1e^{-t/RC}u + K_2\delta\).
  • \(RCh' + h = RCK_2\delta' + (RCK_1 + K_2)\delta + (\ldots)u\)؛ جمله \(u\) صفر است. سمت راست: \(RC\delta'\).
  • \(K_2 = 1\)؛ \(RCK_1 + 1 = 0 \Rightarrow K_1 = -\frac{1}{RC}\).
    •

    \(h(t) = \delta(t) - \dfrac{1}{RC}e^{-t/RC}u(t)\)

    تفسیر: در لحظه ضربه، خازن اتصال کوتاه است و کل ضربه ولتاژ روی R می‌افتد (جمله \(\delta\)). بعد، خازن باردار شده و جریان را برعکس می‌کند (جمله منفی).

    جمع‌بندی فصل

    • \(h(t)\) برای \(t > 0\) = جواب همگن؛ ضرب در \(u(t)\).
    • \(m \ge n\) ⇒ به‌علاوه \(\delta, \ldots, \delta^{(m-n)}\).
    • تطبیق ضرایب: جمله‌های \(u\) خودشان حذف می‌شوند؛ ضرایب \(\delta^{(k)}\) را برابر بگذارید.
    • \(m = 0\): شرایط معادل \(y^{(n-1)}(0^+) = b_0\)، بقیه صفر.
    • بررسی با \(H(s)\): تقسیم + کسر جزئی. \(s = \int h\)، \(s(\infty) = H(0)\).
